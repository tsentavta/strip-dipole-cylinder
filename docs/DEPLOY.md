# 📦 Инструкция по развёртыванию на GitHub + Streamlit Cloud

Эта инструкция проведёт вас через процесс публикации программного комплекса на GitHub и развёртывания веб-приложения в облаке через Streamlit Community Cloud (бесплатно).

**Время выполнения:** ~20 минут

## 📋 Что вам потребуется

- ✅ Учётная запись GitHub (бесплатно: [github.com/signup](https://github.com/signup))
- ✅ Установленный Git ([git-scm.com](https://git-scm.com/downloads))
- ✅ Папка с готовым кодом проекта (этот репозиторий)
- ✅ Учётная запись Google или GitHub (для Streamlit Cloud)

---

## Шаг 1. Создание GitHub-репозитория

### 1.1. Войдите в GitHub

Откройте [github.com](https://github.com) и войдите в свой аккаунт.

### 1.2. Создайте новый репозиторий

1. Нажмите на **«+»** в правом верхнем углу → **«New repository»**
2. Заполните форму:
   - **Repository name:** `strip-dipole-cylinder`
   - **Description:** `Программный комплекс для расчёта полосковых вибраторных излучателей на диэлектрическом цилиндре методом СИУ`
   - **Public** (чтобы Streamlit Cloud мог развернуть бесплатно)
   - ❌ **НЕ** добавляйте README, .gitignore или LICENSE — они уже есть в проекте
3. Нажмите **«Create repository»**

### 1.3. Скопируйте адрес репозитория

После создания GitHub покажет страницу с командами. Скопируйте URL вида:
```
https://github.com/tsentavta/strip-dipole-cylinder.git
```

## Шаг 2. Загрузка кода в репозиторий

### 2.1. Откройте терминал в папке проекта

**Windows (PowerShell):**
```powershell
cd C:\путь\к\strip-dipole-cylinder
```

**macOS / Linux:**
```bash
cd /путь/к/strip-dipole-cylinder
```

### 2.2. Инициализируйте Git и сделайте первый коммит

```bash
# Инициализация репозитория
git init

# Добавление всех файлов
git add .

# Первый коммит
git commit -m "Initial commit: программный комплекс для полоскового вибратора на цилиндре"

# Указание основной ветки
git branch -M main

# Подключение удалённого репозитория (замените tsentavta на ваш username, если другой)
git remote add origin https://github.com/tsentavta/strip-dipole-cylinder.git

# Отправка кода
git push -u origin main
```

### 2.3. Авторизация

При первом push GitHub попросит логин и пароль. **Используйте Personal Access Token вместо пароля:**

1. Перейдите в [github.com/settings/tokens](https://github.com/settings/tokens)
2. **Generate new token (classic)**
3. Дайте имя, например `streamlit-deploy`
4. Поставьте галочку `repo` (полный доступ к репозиторию)
5. Скопируйте токен (он показывается только один раз!)
6. Используйте его как пароль при `git push`

> 💡 **Альтернативно:** установите [GitHub CLI](https://cli.github.com/) и выполните `gh auth login` — авторизация через браузер.

### 2.4. Проверьте загрузку

Откройте `https://github.com/tsentavta/strip-dipole-cylinder` в браузере. Вы должны увидеть все файлы и красиво отрендеренный README.

## Шаг 3. Развёртывание на Streamlit Cloud

### 3.1. Зарегистрируйтесь на Streamlit Cloud

1. Откройте [share.streamlit.io](https://share.streamlit.io)
2. Нажмите **«Sign up»** или **«Continue with GitHub»**
3. Авторизуйтесь через GitHub (рекомендуется)
4. Разрешите Streamlit доступ к вашим репозиториям

### 3.2. Создайте новое приложение

1. На главной странице нажмите **«Create app»**
2. Выберите **«From existing repo»**
3. Заполните форму:
   - **Repository:** `tsentavta/strip-dipole-cylinder`
   - **Branch:** `main`
   - **Main file path:** `app.py`
   - **App URL:** `strip-dipole-cylinder` (можно оставить по умолчанию)
4. Нажмите **«Deploy»**

### 3.3. Дождитесь развёртывания

Первое развёртывание занимает 3-5 минут:
- Streamlit клонирует репозиторий
- Устанавливает зависимости из `requirements.txt`
- Запускает `app.py`

При успехе вы увидите ваше приложение по адресу:
```
https://strip-dipole-cylinder.streamlit.app
```

### 3.4. Поделитесь ссылкой

Эта ссылка **постоянная** и работает 24/7. Поделитесь ею:
- 📋 С членами защитной комиссии
- 📋 В презентации защиты (можно сделать QR-код через [qr-code-generator.com](https://www.qr-code-generator.com/))
- 📋 В описании репозитория на GitHub
- 📋 В тексте магистерской диссертации (как ссылка на программный продукт)

## Шаг 4. Дальнейшая работа

### 4.1. Обновление кода

При внесении изменений:

```bash
# Внесите изменения в код
# ...

# Загрузите обновления
git add .
git commit -m "Описание изменений"
git push
```

Streamlit Cloud **автоматически** перезапустит приложение через 30-60 секунд.

### 4.2. Просмотр логов

Если приложение не запускается:
1. Откройте ваше приложение на [share.streamlit.io](https://share.streamlit.io)
2. Нажмите **«Manage app»** → **«Logs»**
3. Посмотрите ошибку

### 4.3. Настройка приложения

В Streamlit Cloud в разделе **Settings** можно:
- Изменить **App URL** (один раз бесплатно)
- Настроить **Python version** (по умолчанию — последняя стабильная)
- Добавить **Secrets** (переменные окружения, если нужны)

## 🆘 Возможные проблемы

### Ошибка: "ModuleNotFoundError"

**Причина:** не все зависимости указаны в `requirements.txt`.

**Решение:** добавьте недостающую библиотеку в `requirements.txt`, сделайте `git push`.

### Ошибка: "Memory limit exceeded"

**Причина:** расчёт превышает 1 GB RAM (это редко).

**Решение:** уменьшите размерности по умолчанию в `app.py`:
```python
default_k, default_n, default_h, default_t = 6, 8, 150, 73  # вместо 12, 15, 400, 181
```

### Приложение очень медленное

**Причина:** холодный старт после долгого простоя.

**Решение:** подождите 30-60 секунд после первого обращения.

### Не работает кэширование `@st.cache_data`

**Причина:** функция возвращает не-хэшируемый объект.

**Решение:** убедитесь, что вход в кэшированную функцию — кортеж/строка, а не словарь.
