## [1.0.0] — 2026-05-10

### 🎉 Первый публичный релиз

### Добавлено
- **Расчётное ядро** — пакет `strip_dipole_cylinder` с 4 модулями:
  - `cylinder_spectral.py` — матрица поверхностных импедансов цилиндра
  - `sie_solver.py` — метод Бубнова–Галёркина с базисом Чебышёва
  - `far_field.py` — метод стационарной фазы для дальней зоны
  - `compute.py` — высокоуровневое API
- **Веб-интерфейс** на Streamlit (`app.py`) с 7 функциональными вкладками
- **6 пресетов параметров** из научной литературы
- **3 режима производительности**: быстрый/сбалансированный/точный
- **Кэширование** через `@st.cache_data` для интерактивности
- **Интерактивные графики** Plotly (полярные ДН, 3D-геометрия)
- **Экспорт результатов** в CSV и JSON
- **Глоссарий** из 14 ключевых терминов
- **Поддержка Docker** — multi-stage Dockerfile + docker-compose.yml
- **CI через GitHub Actions** — тесты на Python 3.9, 3.10, 3.11, 3.12
- **14 юнит-тестов** для верификации алгоритмов
- **Документация**: README, DEPLOY.md, CONTRIBUTING.md, шаблоны issue/PR
- **Лицензия MIT**

### Производительность
- Спектральная сходимость метода: погрешность 10⁻⁴ при K=12, 10⁻⁵ при K=20
- Время расчёта одного варианта: 5–40 секунд в зависимости от режима

### Документация
- Полное описание метода в README и вкладке «О методе»
- BibTeX-цитата для научных публикаций
- Скриншоты для всех ключевых вкладок
- Пошаговая инструкция по развёртыванию на GitHub + Streamlit Cloud
