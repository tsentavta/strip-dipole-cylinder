# Release Notes — v1.0.0

**Дата релиза:** 10 мая 2026

## 🎯 О релизе

Первый публичный релиз программного комплекса **strip-dipole-cylinder** — специализированного программного обеспечения для электродинамического анализа полосковых вибраторных излучателей, расположенных на боковой поверхности диэлектрического цилиндра.

Релиз приурочен к защите магистерской диссертации Е.М. Кузнецова в Поволжском государственном университете телекоммуникаций и информатики (ПГУТИ, Самара) по направлению 09.04.03 «Прикладная информатика».

---

## ✨ Основные возможности

### Расчётное ядро (Python-пакет `strip_dipole_cylinder`)

- 🔢 **Реализация самосогласованного метода СИУ** с регуляризацией Карлемана–Векуа
- 📐 **Метод Бубнова–Галёркина** с базисом полиномов Чебышёва второго рода — спектральная скорость сходимости
- 📡 **Расчёт полевых характеристик** методом стационарной фазы для дальней зоны
- ⚡ **Защита от особых точек** спектра при численном интегрировании
- 🔧 **Векторизация вычислений** через NumPy для высокой производительности
- 📊 **Высокоуровневое API** с функцией `compute_pattern(params)` для одного вызова

### Веб-интерфейс (`app.py`)

- 🌐 **Streamlit-приложение** с 7 функциональными вкладками:
  - 🏠 Главная — описание программы, реквизиты работы
  - 🎯 Расчёт — основной режим работы с прогресс-баром и метриками
  - 📊 Сравнение — параметрические исследования (до 6 значений на одном графике)
  - 📐 Геометрия — интерактивная 3D-визуализация структуры
  - 💾 Экспорт — выгрузка результатов в CSV и JSON
  - 📚 Глоссарий — 14 ключевых терминов с формулами
  - 📖 О методе — описание метода, литература, BibTeX-цитата

- 📋 **Шесть готовых пресетов параметров**:
  - Шатров (рис. 3.21) — параметры из основополагающей работы
  - Цилиндр с ε₁=2, ε₁=3.5, ε₁=5
  - Полноволновой вибратор (2l = λ)
  - Короткий вибратор (2l = λ/4)

- ⚖️ **Три режима производительности**: ⚡ быстрый / ⚖️ сбалансированный / 🎯 точный

- 🎨 **Интерактивные графики Plotly**: полярные ДН в дБ, графики распределения тока, 3D-геометрия — с возможностью масштабирования, перемещения, экспорта в PNG/SVG/HTML

- 💾 **Кэширование** через `@st.cache_data` — повторные расчёты с теми же параметрами возвращаются мгновенно

### Архитектура и DevOps

- 🐳 **Поддержка Docker** — multi-stage build для минимизации образа

## 🐛 Известные ограничения

- **Только цилиндрическая геометрия** — поддержка сферической и конической геометрий планируется в v2.0
- **Только одиночный излучатель** — поддержка антенных решёток в roadmap
- **Изотропные среды** — учёт анизотропии диэлектрика в плане v2.x
- **Без диэлектрических потерь** — учёт мнимой части проницаемости в плане v1.1
- **Только продольное возбуждение** — поперечная составляющая тока пренебрегается (узкая полоска)
- **Время расчёта в облаке** может быть в 1.5–2 раза больше локального из-за общего CPU на Streamlit Cloud
- **Холодный старт** приложения после долгого простоя (>7 дней) — около 30–60 секунд

## 🚀 Установка и использование

### Запуск в облаке

🌐 [strip-dipole-cylinder.streamlit.app](https://strip-dipole-cylinder.streamlit.app) — без установки

### Локально через pip

```bash
git clone https://github.com/tsentavta/strip-dipole-cylinder.git
cd strip-dipole-cylinder
pip install -r requirements.txt
streamlit run app.py
```

### Через Docker

```bash
docker compose up
```

или вручную:

```bash
docker build -t strip-dipole-cylinder .
docker run -p 8501:8501 strip-dipole-cylinder
```

### Как Python-библиотека

```python
from strip_dipole_cylinder import compute_pattern, default_params

params = default_params()
params['eps1'] = 3.5
result = compute_pattern(params)
print(f"Z = {result['Z_input']:.2f} Ом")
```
